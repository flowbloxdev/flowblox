Description:
FlowBlox is an open-source visual automation platform for extracting, transforming, and processing data from websites, files, databases, and APIs. Users compose reusable workflow blocks or ask an integrated AI Assistant to create and configure workflows that remain fully inspectable and editable. Built-in testing and configuration generators help validate results and derive extraction logic from examples. Workflows execute locally and can be automated through desktop, command-line, or service-based execution.

WEBSITE DOWNLOAD RECOMMENDATION
-------------------------------

Host release files on GitHub Releases. Use flowblox.net as the user-facing entry
page with platform, version, requirements, release notes, signing status, and
links to the GitHub-hosted files. Keeping a second copy of each MSI on the web
server is unnecessary unless a separate distribution requirement calls for it.

The simplest permanent website button links to /releases/latest above.
For an immediate MSI download, link to the exact versioned asset URL above and
update that link when a new release is published.

GitHub also supports /releases/latest/download/ASSET_NAME, but ASSET_NAME must
match exactly. Our MSI filename contains the version, so a link using the 1.0.0
filename will not automatically find the 1.1.0 MSI in the latest release.

HOW VERSION 1.0.0 STARTS
------------------------

First merge the CI/release workflows and scripts into main and let CI pass.
Use the intended clean main commit for the tag.

Create this exact first tag locally (no upload, no build starts):
git tag -a v1.0.0 -m "FlowBlox 1.0.0"

Only when ready to publish, push that tag yourself:
git push origin v1.0.0

That push automatically starts "Release Windows x64". No manual Actions start
or manually created GitHub Release is needed. The workflow validates the tag,
runs checks and UnitTest-category tests, builds the WiX MSI and checksum, then
publishes the GitHub Release. A failed check/build prevents publication.

Creating a local tag alone does not start GitHub Actions.
This document does not create or push any tag.

For later versions, the default helper increments MINOR:
scripts/New-FlowBloxReleaseTag.ps1
Major and patch/hotfix increments require an explicit request. The helper does
not push. For the exact initial version 1.0.0 use the explicit tag command above;
the next-version helper would increment the current baseline instead.
