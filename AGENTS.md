# Repository instructions

Read and follow [AGENT_CONVENTIONS.md](AGENT_CONVENTIONS.md) before changing this repository.

For any release/tag request, first read [docs/releases.md](docs/releases.md).
Default to a **minor** increment and create **only a local annotated tag** with
`scripts/New-FlowBloxReleaseTag.ps1`. Increase major or patch/hotfix only when
explicitly requested. Never push a tag or publish a release unless the user
explicitly requests that separate action.
