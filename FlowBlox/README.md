# FlowBlox — Obsolete WinForms Application

This project is obsolete and is no longer used as the main application. The main
application has been fully ported to [FlowBlox.Avalonia](../FlowBlox.Avalonia/).

This directory is retained only as a knowledge base and a reference for comparing
the Avalonia application with the legacy WinForms implementation. It is scheduled
for removal.

Develop new application features and fixes in `FlowBlox.Avalonia`.

For current project information, see the [main repository README](../README.md).
